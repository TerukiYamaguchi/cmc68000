# MC68010 実装仕様

MC68010 は `MC68K_MODEL_68010` で選択する。基本 decode table の上に
`register_68010_ops()` を適用して、68010 固有 opcode と既存 opcode の規則を上書きする。

## 追加状態と命令

- VBR、SFC、DFC を state に保持し、公開 snapshot で観測できる。
- MOVEC は SFC、DFC、USP、VBR を対象にする。
- MOVES は SFC/DFC から function code を選んで EA access を行う。
- RTD と BKPT を実装する。MOVE from SR は特権命令である。

## 例外と再開

通常例外 frame は format word を含む format 0 frame になる。group 0 exception は format 8
frame を使う。RTE は frame format を検証し、68010 の retry 設定を持つ bus/address error frame
については、保存した命令先頭から再開する。

## timing

68010 固有の命令・例外値と、68000 から異なる基本値は model timing profile で解決する。
EA cost は命令 handler が明示的に加算する。
