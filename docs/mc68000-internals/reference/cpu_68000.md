# MC68000 実装仕様

## 実行モデル

`mc68k_create()` は MC68000 model の CPU を作る。`mc68k_reset()` は vector 0 と 1 から
SSP と PC を読む。`mc68k_execute()` は命令境界まで実行し、指定 budget を超過しても
命令の途中では停止しない。

CPU state は内部型である。公開 API は `include/mc68000/cpu.h`、公開 snapshot は
`mc68k_regs_t` を使う。モデルは作成時に固定され、実行中の変更はできない。

## メモリと EA

バス access は `mc68k_bus_t` callback を通す。word/long の奇数 access は callback に
到達する前に address error になる。callback の `false` は bus error である。

EA の評価は `ea_helpers.c` に一元化する。A7 の byte postincrement/predecrement は 2 byte、
その他の address register は operand size だけ動かす。68000 では brief index extension
だけを受理し、scale は 1 として扱う。

## 特権・例外・割り込み

S bit に応じて A7 と USP/SSP を交換する。特権命令は状態や EA を変更する前に privilege
violation を起こす。通常例外は 6 byte frame、address error と bus error は 14 byte frame
を使う。exception-frame 作成中の group 0 fault は CPU を halted state にする。

IRQ は命令境界だけで受理する。`mc68k_set_irq()` は pending level を更新し、iack callback
が vector を選ぶ。level 7 は mask に関係なく受理する。

## デコードと timing

decode table は 65536 個の handler pointer からなる。未登録 opcode は ILLEGAL、line A/F は
対応する line exception handler になる。各 handler は消費 cycle を返す。68000 の基本値と
EA fetch cost は `cycles.c` が持つ。
