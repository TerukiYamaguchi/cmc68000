# MC68020 実装仕様

MC68020 は `MC68K_MODEL_68020` で選択する。68010 までの登録に続いて 68020 arithmetic、
bitfield、system handler を適用する。

## 実効アドレス

68020 以降は full-format index extension を受理する。base/index suppress、base displacement、
pre/post-indexed memory indirect、outer displacement を `ea_helpers.c` が処理する。予約 encoding
は exception state にして命令を中止する。

## 追加命令

実装には bit field、CAS、CAS2、CHK2/CMP2、LINK.L、TRAPcc、long branch と 68020 算術拡張を含む。
CAS/CAS2 と TAS だけが locked RMW access を要求する。他の read-modify-write 命令は read と
write を別 bus cycle として発行する。

## 例外

通常例外は format 0 frame を使う。group 0 の frame と SSW は `m68000.c` がモデル別に構築する。
68020 以降の fault 時には命令開始時の register snapshot を保持し、RTE の再開に使う。

## timing

68020 profile は命令 class と EA cost kind を別に持つ。full-format EA の cost は extension の
形式を記録した EA descriptor から決める。
