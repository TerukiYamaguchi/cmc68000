# MC68030 / MC68EC030 実装仕様

68030 と 68EC030 は 68020 命令を継承し、`ops_68030_mmu.c` が PMMU 関連 opcode を登録する。
両者は同じ timing profile を共有する。

## MC68030

TC、CRP、SRP、TT0、TT1、MMUSR を state に保持する。PLOAD、PFLUSH、PTEST、PMOVE を通じて
translation cache と table walk を操作する。論理 access は function code、supervisor 状態、
read/write 属性を伴って translation に渡す。

## MC68EC030

EC030 は PMMU table walk を持たず、AC0/AC1 と ACUSR による access-control を使う。公開 MMU
snapshot では `tt0`/`tt1`/`mmusr` がそれぞれ AC0/AC1/ACUSR を表し、`tc`/`crp`/`srp` は zero である。

## cache と bus

68030 cache-inhibit 判定は access-control result を参照する。MMU table walk は物理 bus access と
して実行し、callback が返す bus wait を実行 cycle に加算する。
