# MC68040

## 1. 目的と対象範囲

`MC68K_MODEL_68040` の MMU、cache、内蔵 FPU、例外 frame、cycle の差分を定義する。

## 2. 実装状態

68040 固有の MMU、D-cache 操作、CINV、CPUSH、MOVE16、F-line/FPU 経路を実装する。FPU 構成は
`MC68K_FPU_68040`（内蔵）または `MC68K_FPU_NONE_040`（FPU なし）を選択できる。

## 3. 設計の要点

| 決定 | 理由 | 検証 |
| --- | --- | --- |
| MMU と cache を専用モジュールに分離する | 68020/030 の変換経路と責務を分ける | `test_68040_mmu`、`test_68040_cache` |
| data fault を WB2 保留ストアと再実行に分ける | format $7 frame の書戻し情報を再現する | `test_68040_exception` |
| 非整列 access は分割して cache へ渡す | cache access を単一 32-bit word に保つ | `test_68040_cache` |

## 4. 構成とデータモデル

MMU register は `mc68k_get_mmu040_regs()` で観測できる。変換は `ops_68040_mmu.c`、D-cache と
CINV/CPUSH/MOVE16 は `ops_68040_cache.c`、内蔵 FPU は `ops_68040_fpu.c` が担当する。

## 5. インターフェース、レジスタ、入力

68040 は URP、SRP、TC、DTT0/1、ITT0/1、MMUSR を保持する。PFLUSH と PTEST は 040 MMU
handler が扱う。通常の memory callback には変換後の物理アドレスが渡る。

## 6. 動作仕様

table-search read は D-cache hit を利用するが、miss 時に cache line を割り当てない。
68040 の非整列 data access は address error にせず、byte/word access へ分割する。

data access error は format $7 frame を使う。命令内の単純な write が ATC fault した場合は
WB2 として保留し、命令完了後に access error を配送する。handler が写像を修正して RTE すると、
frame の WB2 情報から書戻す。read fault、RMW、命令 fetch、分割 access、MOVEM などは
命令開始時の状態へ戻して再実行する。

FPU なし構成の cpID 1 命令は、通常の F-line 例外ではなく 040 の未実装 FPU 例外経路を使う。
pipeline overlap と cache-miss 転送時間の完全なモデル化は行わない。

## 7. 実装上の対応

| モジュール | 責務 |
| --- | --- |
| `ops_68040_mmu.c` | translation、PFLUSH、PTEST、MMU fault |
| `ops_68040_cache.c` | D-cache、CINV、CPUSH、MOVE16、WB2 補助 |
| `ops_68040_fpu.c` | 内蔵 FPU 命令と FSAVE/FRESTORE |
| `m68000.c` | format $7 frame、例外配送、bus wait |

## 8. 互換性と既知の制約

040 の MMU、cache、FPU、例外 frame は前世代と非互換である。cycle は公称値と bus wait を扱うが、
pipeline overlap と cache-miss 転送時間は完全にはモデル化しない。
