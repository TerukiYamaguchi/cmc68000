# MC68020

## 1. 目的と対象範囲

`MC68K_MODEL_68020` の、68010 から追加される命令、full-format 実効アドレス、例外再開、
cycle profile を定義する。68010 までの共通仕様は [MC68010](cpu_68010.md) を参照する。

## 2. 実装状態

68020 arithmetic、bit field、system handler を基本 decode table へ追加する。bit field、CAS、
CAS2、CHK2/CMP2、LINK.L、TRAPcc、long branch、68020 算術拡張を実装する。FPU は
`MC68K_FPU_NONE`、`MC68K_FPU_68881`、`MC68K_FPU_68882` を選択できる。

## 3. 設計の要点

| 決定 | 理由 | 検証 |
| --- | --- | --- |
| full-format EA を EA helper に集約する | 命令 handler ごとの拡張語解釈を避ける | `test_68020_ea` |
| locked RMW は CAS/CAS2/TAS だけに付与する | bus callback へ必要な排他属性だけを伝える | `test_68020_arith` |
| 命令 class と EA cost を分離する | full-format EA の cycle を一貫して算出する | `test_cycle_ea` |

## 4. 構成とデータモデル

`ea_helpers.c` は full-format index extension を解釈し、EA descriptor に base/index suppress、
base displacement、memory indirect、outer displacement の情報を保持する。fault 時の register
snapshot は RTE による再開に使う内部状態である。

## 5. インターフェース、レジスタ、入力

公開 CPU API は前世代と共通である。モデルは
`mc68k_create_model(bus, MC68K_MODEL_68020)` で選択する。外付け FPU を使う場合は
`mc68k_create_model_with_fpu()` と CPU 空間 callback を使う。

## 6. 動作仕様

full-format index extension は base/index suppress、base displacement、pre/post-indexed memory
indirect、outer displacement を受理する。予約 encoding は命令を中止して例外として扱う。

通常例外は format 0 frame を使う。group 0 frame と SSW はモデル別に構築し、fault 時には
命令開始時の register snapshot を保存する。RTE は再開可能な frame を復帰する。

CAS、CAS2、TAS の operand access は locked RMW として bus callback に通知する。他の
read-modify-write 命令は独立した read / write bus cycle を発行する。

命令語または拡張語の取得が fault を設定した後は、同じ命令内の以後の取得を行わない。
`cpu_fetch_word()` は非 MC68000 の全モデルで、`CPU_NORMAL` 以外なら bus access を発行せず
0 を返す。この契約により、long branch や long 即値の上位語取得が失敗しても下位語への余分な
read、I/O 側の副作用、余分なサイクル計上を防ぐ。68020 以降で共有する契約であり、68030、68040、
68060 にも適用する。

## 7. 実装上の対応

| モジュール | 責務 |
| --- | --- |
| `ops_68020_arith.c` | 算術拡張、CAS、CHK2/CMP2 |
| `ops_68020_bitfield.c` | bit field 命令 |
| `ops_68020_system.c` | system 命令、TRAPcc、LINK.L など |
| `ea_helpers.c` | full-format EA |
| `cycles.c` | 68020 profile と EA cost |

## 8. 互換性と既知の制約

68020 は 68030 以降の PMMU、68040 以降の内蔵 cache／FPU を持たない。68020 より前の
モデルでは full-format EA と追加命令は実行できない。

## 9. テストと受入条件

| テスト | 検証対象 |
| --- | --- |
| `test_68020_ea`、`test_lea_full` | full-format EA |
| `test_68020_arith`、`test_68020_bitfield` | 算術拡張、CAS、bit field |
| `test_68020_misc`、`test_68020_decode_matrix` | 追加命令と decode |
| `test_68020_restart_faults`、`test_68020_misalign` | 例外再開と非整列 access |
| `test_fetch_word_fault_stop` | long branch と long 即値の上位語 fault 後に下位語を取得しないこと |
| `test_cycle_ea`、`test_cycle_phase2b` | cycle と EA cost |

受入条件は、追加命令、full-format EA、RTE 再開、RMW 属性、cycle が上記テストと一致すること。
